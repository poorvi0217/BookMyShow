# BookMyShow Clone 🎬🎟️

A full-stack **ticketing web app** to browse and book movies & live events.

### 🚀 Features
* **Dynamic Browsing:** Filter shows by location, genre, and language.
* **Live Seating:** Interactive, responsive seat grid mapping.
* **Secure Booking:** User authentication with structured relational data.

**Tech Stack:** Java • Spring Boot • Spring Data JPA • MySQL • HTML5 • CSS3 • JavaScript
